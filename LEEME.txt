EL CERRO - PAGINA WEB
====================
Sello musical de Cali. Este ZIP contiene la pagina completa, lista para
editar y para subirla a internet sin depender de Lovable.


1. QUE HAY ADENTRO
------------------
src/routes/index.tsx      -> Inicio (portada del lanzamiento + Wazko + Tenebris)
src/routes/wazko.tsx      -> Pagina de Wazko
src/routes/tenebris.tsx   -> Pagina de Tenebris
src/routes/contacto.tsx   -> Pagina de Contacto (Instagram y Correo)
src/routes/__root.tsx     -> Menu de arriba y pie de pagina (estan en todas)
src/components/ArtistPage.tsx -> Plantilla que usan las paginas de artistas
src/styles.css            -> Colores, letra y espaciado de toda la pagina
public/                   -> La caratula de "Cluedo" y el icono de la pestana

La caratula esta en:
public/__l5e/assets-v1/46422c5d-96b3-4c9a-816e-fd39b69d38a4/cluedo.jpg


2. VERLA EN TU COMPUTADOR
-------------------------
Necesitas Node.js 20 o mas nuevo (https://nodejs.org).
Descomprime el ZIP, abre la carpeta y ejecuta:

  npm install
  npm run dev

Luego abre la direccion que aparece (normalmente http://localhost:8080).
Cada vez que guardes un archivo, la pagina se actualiza sola.


3. SUBIRLA A VERCEL
-------------------
1) Sube esta carpeta a un repositorio de GitHub (o GitLab).
2) Entra a vercel.com -> Add New -> Project -> importa ese repositorio.
3) En "Build & Development Settings" deja:
     Framework Preset:  Other
     Build Command:     npm run build
     Install Command:   npm install
4) Agrega una variable de entorno (Environment Variables) con:
     NITRO_PRESET = vercel
5) Dale a Deploy.

Esa variable le dice al proyecto que empaque la pagina en el formato que
Vercel entiende. Sin ella, la pagina se construye para Cloudflare.

Si prefieres la consola, desde la carpeta:
  npm i -g vercel
  NITRO_PRESET=vercel vercel --prod


4. SUBIRLA A NETLIFY
--------------------
Mismo idea: sube el repositorio y conéctalo en netlify.com.
  Build Command:    npm run build
  Publish directory: dist
  Variable de entorno: NITRO_PRESET = netlify

Las funciones del servidor se generan solas en .netlify/functions-internal.


5. SUBIRLA A CLOUDFLARE PAGES
-----------------------------
En el panel de Cloudflare Pages:
  Build Command:     npm run build
  Build output directory: dist
  Variable de entorno: NITRO_PRESET = cloudflare-pages


6. PROBAR LA VERSION FINAL ANTES DE SUBIRLA
-------------------------------------------
  npm run build
  PORT=3000 node .output/server/index.mjs
  (abre http://localhost:3000)

Nota: para esa prueba usa NITRO_PRESET=node_server; es la version que corre
con Node puro en cualquier servidor.

----------------------------
- La portada sigue en modo demo: muestra "Cluedo" de Midas Alonso.
  Para el sencillo real de Wazko, cambia en src/routes/index.tsx:
  el titulo (h1), el nombre del artista, la caratula y los enlaces.
- El boton "Apple Music" y el boton "YouTube" abren una busqueda de la
  cancion, no el tema directo. Pega ahi los enlaces reales.
- Las paginas de Wazko y Tenebris tienen los tres botones con enlace
  provisional ("#"): reemplaza los href="#" por las direcciones reales.
- Falta la foto de cada artista (ahora sale un recuadro vacio).
- El pie de pagina y el menu dicen "El Cerro"; el correo es
  elcerromusicgroup@gmail.com y el Instagram @elcerromusic_.
